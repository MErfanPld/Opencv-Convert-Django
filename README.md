# 🎨 OpenCV Image Converter with Django

A web-based image processing application built with **Django** and **OpenCV** that allows users to upload images and apply different image transformations and filters in real time.

This project demonstrates the integration of **computer vision** features with a modern Django backend architecture.

OpenCV is widely used for image processing, object detection, and computer vision applications. :contentReference[oaicite:0]{index=0}

# ⚙️ Installation

## 1. Clone the repository

```bash
git clone https://github.com/MErfanPld/Opencv-Convert-Django.git
```

## 2. Navigate to the project directory

```bash
cd Opencv-Convert-Django
```

## 3. Create virtual environment

```bash
python -m venv venv
```

---

## 4. Activate virtual environment

### Linux / macOS

```bash
source venv/bin/activate
```

### Windows

```bash
venv\Scripts\activate
```

---

## 5. Install dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Run the Project

```bash
python manage.py runserver
```

Server will run on:

```bash
http://127.0.0.1:8000
```
